# Meals report (Manager, "Meals")

For a period (default: this month, school days): meals served per meal type and how many different students; meals per day;
meals per student (by meal, total, last meal) with a filter by meal and a search by number or name; the plans that end within
14 days and have not been renewed; and a CSV (student number, grade, a count per meal, total; no names).
Counts come from the meal screen: one record per student, meal and school day. Every CSV export is written to the audit log.
