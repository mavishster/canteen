# School settings

All on **Settings** (admin). A figure is stored in the school's currency; leaving a box empty goes back to the default.

| Setting | Where it is used | Default |
|---|---|---|
| Spending caps by grade band (daily, weekly) | the till refuses a purchase that would pass the cap; parents can only go lower | none |
| Most one purchase may cost | the till (a copied card cannot empty an account in one go) | none |
| Buying hours (days, time windows) | the till | always open |
| Smallest top-up | parent top-ups | $1 (4,000 riel) |
| Riel per US dollar | converting a payment made in the other currency | 4,100 |
| Low balance warning | default threshold for the alert to parents | $2 (8,000 riel) |
| Sell by student number | till and meal screen | on |

Product categories are a managed list (**Categories**): products pick from it, near-duplicate names are refused, and duplicates can be merged.
Currency and time zone cannot be changed here on purpose.
